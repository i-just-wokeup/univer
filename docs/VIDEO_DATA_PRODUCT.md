## 확정된 것

### 원본은 절대 팔지 않는다

- 법적 3중: 저작권(올린 사람) + 초상권(찍힌 사람) + 개인정보(얼굴)
- **나가는 순간 통제 종료.** 학습에 쓰든 재판매하든 막을 수도 확인할 수도 없다
- 이용자가 나중에 지워도 이미 나간 건 못 돌린다
- **원본은 한 번 팔고 끝. 집계만 팔면 계속 사야 한다**

### 층 구조

| 단계 | 내용 | 판매 |
|---|---|---|
| L0 | 원본 사진·영상 | **절대 안 팜** |
| L1 | 게시물별 태그 (작성자 연결됨) | **안 팜** |
| L2 | 태그 집계 숫자 (주·월별) | 판매 |
| L3 | L2 + 사람 해석 리포트 | 판매 |

밖으로 나가는 게 집계뿐이면 **개인정보 제3자 제공이 아니다.** 필요한 건 「제공 동의」가 아니라 **「분석해도 된다는 동의」**.

### 태깅 설계

**흐름**
```
동의함 + 전체공개 + 미삭제 글
  → 사진 그대로 / 영상은 Cloudflare 썸네일 3~4장
  → 모델에 보내 정해진 형식으로 답 받기
  → 태그 저장 → 집계
```
하루 한 번 배치. 실시간 불필요.

**모델** — 멀티모달 AI로 시작(태그 목록을 말로 바꿀 수 있고 한국 맥락을 안다). 브랜드 탐지가 주력이 되면 전용 업체 추가. **직접 학습은 하지 않는다.**

**⚠️ 답을 자유 문장으로 받으면 안 된다.** "카페"·"커피숍"·"까페"가 따로 세어지면 집계가 무의미해진다. 정한 목록 중에서만 고르게 한다.

| 항목 | 값 |
|---|---|
| 장소 | 카페 / 도서관 / 강의실 / 식당 / 술집 / 헬스장 / 집 / 야외 / 이동중 / 기타 |
| 활동 | 공부 / 식사 / 운동 / 모임 / 이동 / 공연 / 기타 (복수) |
| 사람 수 | 0 / 1 / 2 / 3명 이상 (**얼굴 인식 아님, 수만**) |
| 브랜드 | 자유 텍스트 + 확신도 |

**같이 저장할 것** — 확신도(낮으면 집계 제외), 🔴 **모델 이름·버전 + 분석 시각**. 모델이 바뀌면 같은 사진에 다른 태그가 붙어 **작년 수치와 비교가 불가능해진다.**

### 집계 규칙 5가지

1. **고유 작성자 수로 센다** (게시물 수 아님). 한 명이 다섯 번 올리면 「급상승」이 된다
2. **소집단 역추적 방지** — 최소 인원 미만 미공개 / 다중 교차 조회 금지 / 구간 반올림
3. **학사일정 착시** — 시험기간 도서관, 방학 여행은 달력이지 트렌드가 아니다. 제거하려면 13개월치 필요
4. **사용자 구성 변화 기록** — 신입생 유입이 「새 트렌드」로 보인다
5. **크루공개(`close_friends`) 제외** — 메타도 공개 게시물만 쓴다

### 트렌드는 「많이」가 아니라 「변화」

|  | 늘고 있음 | 줄고 있음 |
|---|---|---|
| **많이 나옴** | 주류 | **한물감** ← 돈 됨 |
| 적게 나옴 | **떠오름** ← 제일 돈 됨 | 사라짐 |

계산: 점유율(비율) / 증감률 / **가속도** / **반응 대비** / 신규 등장

💡 **「반응 대비」는 우리만 된다.** 썸트렌드는 언급 횟수는 세도 끝까지 봤는지는 모른다.

### 정확도는 믿는 게 아니라 재는 것

| 항목 | 정확도 |
|---|---|
| 장소 / 활동 / 사람 수 | 높음 |
| 음식 종류 | 중간 |
| 브랜드·로고 | **낮음** — 전용 모델 필요 |
| 분위기·스타일 | ❌ 쓰지 말 것 |

사진 100~200장에 사람이 정답지를 달아 대조한다. **그 숫자가 상품 설명서에 들어간다.**

✅ **일관되게 틀리면 괜찮다.** 카페의 20%를 매번 놓쳐도 「3배 늘었다」는 맞다. 파는 건 절대 개수가 아니라 변화율이다.
⚠️ 단, 모델을 바꾸면 이 논리가 깨진다 → 모델 버전 기록이 필수인 이유.

## 하지 않기로 한 것

같은 논의를 반복하지 않기 위해 남긴다.

- **원본 판매** — 위 참조
- **해시태그·검색어를 재료로** — 해시태그 1개, 검색은 사람 이름이라 가치 0 + 프라이버시 위험
- **얼굴에서 나이·성별·인상착의 추정** — 목적에 불필요하고 민감정보 영역
- **분위기·스타일 태그 판매** — 사람마다도 답이 다름
- **직접 모델 학습** — 로고당 수만 장 라벨 필요
- **인스타 동시 게시** — 프로페셔널 계정 한정이라 타겟 대부분이 잘림 (`DECISIONS.md` 2026-09-16)

## 결정 대기 — 여기서 시작

1. **태그 목록 확정** — 위 4종으로 갈지, 더할지 뺄지
2. **정확도 목표치** — 정답지 몇 장으로 어느 수준을 목표할지
3. **동의 문구** — 약관 라이선스 / 설정 스위치 / 처리방침 수정. 초안은 노션에, **변호사 확인 필수**
4. **판매 경로** — A 직접 리포트 / B 소셜 리스닝 업체에 공급 / C 데이터 마켓플레이스
5. **착수 순서** — 동의 구조가 0단계인 건 확정. 그 다음이 태깅

| | 기존 업체 | 우리 |
|---|---|---|
| 보는 것 | 블로그·커뮤니티의 **글** | **사진·영상 내용** |
| 작성자 | 크롤링이라 **20대인지 추정** | **학교 이메일로 인증된 대학생** |
| 반응 | 언급 횟수만 | **완주율까지** |
| 접근 | 공개 소셜만 | **우리 앱은 못 긁는다** → 그들에게 우리는 구멍 |

**수익모델 지형** — 에브리타임: 광고(MAU 300만, 2024 매출 103.6억, **데이터 안 팜**) / 오픈서베이: 패널(검증 20만) / setlog: 구독 계획(**종단간 암호화라 콘텐츠를 볼 수 없음**) / Reddit: 구글 연 6,000만 달러 / **메타·구글: 안 팜**, 접근권만 판매

💡 **데이터 판매는 광고로 못 버는 곳의 선택지다.** 광고가 되기 시작하면 쥐는 게 더 비싸다 → **장기 계약으로 묶지 말 것.**

- 데이터바우처 공급기업 등록 비용·기간
- 소셜 리스닝 업체가 외부 소스를 사는지 → 직접 문의 필요
