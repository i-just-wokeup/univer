바뀐 점

  • 둥근 카드 제거 → 이미지 풀폭(edge-to-edge) + 각진 모서리. 게시물 사이는 얇은 연보라 띠로 구분.
  • 좋아요·댓글·저장 = 게시물마다 인라인(하단 고정 없음), 탭한 게시물부터 아래로 계속 → 빈 공간 없음.
  • 댓글(말풍선) 탭 → 바텀시트가 아래에서 올라옴(오른쪽 폰). 댓글 목록 + 하단 입력창은 시트 안에 고정.
  • 아바타 동그라미는 유지(일반적). 페이지 배지 라운드만 최소화.
