비율이 달라도 빈 공간이 안 생기는 이유

  • 이미지 프레임 = 게시물 비율(세로 4:5 / 정사각 1:1 / 가로 16:9)에 맞춰 높이만 달라짐.
  • 가운데 영역이 flex로 남는 높이를 다 차지 → 가로 사진처럼 이미지가 짧으면, 그만큼 댓글/본문 영역이 더 넓어질 뿐 아래가 비지 않음.
  • 댓글이 0개여도 그 자리를 "첫 댓글을 남겨보세요" 빈 상태가 채움.
  • 하단 좋아요/입력창은 항상 화면 바닥 고정.
결정해줄 것: 가로/세로 사진을 ① 선택한 비율 프레임에 꽉 채워 크롭(object-cover) 할지, ② 원본 전체를 보이게(여백 생길 수 있음) 할지. 지금 미리보기는 ①(크롭)입니다. 인스타식 ②를 원하면 그렇게도 보여드릴게요.
